## ▋ 一、專案任務背景與核心命題

### 1. 任務起點
2026 年 9 月 29 日，美國總統川普簽署行政命令（EO 14434），強制在聯邦公文中全面廢除「AI（Artificial Intelligence）」，改稱為「SI（Super Intelligence，超級智能）」。身後站著黃仁勳、馬斯克、奧特曼等全球頂級科技寡頭，安靜微笑默認。

### 2. 老魚的終極核心命題（非罵街，而是認知反思）
**這不是一場簡單的政治秀，也不是在罵政客是騙子；這是一場利用「確定性答案」閹割全人類探索欲的集權把戲。**

- **表層操作**：用改名規避法律處罰，將民間人造工具升格為國防戰略武器分預算。
- **深層心理**：上位者利用大眾對「AI 很危險」的集體恐懼，將工具「神格化」，聲稱唯有政府認證才安全；藉由發放一個「確定性的答案（由白宮背書）」，給大眾虛假的「安心感」，從而剝奪人民監督權，要求大眾服從命令。
- **陶哲軒核彈級連線**：大腦一旦接受了「確定性的答案」，尋找其他可能性的探索欲就徹底關機（陶哲軒的 Contamination 污染理論）。
- **文章使命**：引導讀者看破這個局，不被溫水煮青蛙，將自身思維從第一層（被動接受答案）提升到第二層（看清代價），最終落地到第三層（陶哲軒 Math 2.0 的人生提問與轉譯能力）。

## ▋ 三、老魚親定核心觀點與精闢比喻庫

Codex 撰寫時，**必須 100% 沿用老魚以下四大精闢比喻與洞察鏈條**：

### 1. 英文名詞拆解：Artificial（人造）換成 Super（超級）
- **AI = Artificial Intelligence（人工智慧）**：A 是「人造的」。它是人做出來的民間工具，跟算盤、電風扇一樣，會出錯，必須受法律約束。
- **SI = Super Intelligence（超級智能）**：S 是「超級的」。川普把人造砍掉，換成超級，直接吹捧成超越人類的神級存在。

### 2. 生活真實案例：神奇寶貝被官方硬改成寶可夢（名詞脫鉤）
- **台灣真實歷史**：我們從小叫「神奇寶貝」，後來官方公告硬改叫「寶可夢」。皮卡丘還是那隻黃色放電老鼠，玩法完全沒變。
- **學校規矩比喻**：校規寫「校內嚴禁玩神奇寶貝」，學生拿出來被抓，只要說：「我玩的是寶可夢，校規管神奇寶貝，你罰不到我！」
- **對照現實**：歐盟花了五年寫幾百頁《AI 法典》準備罰巨頭幾千億；川普大筆一揮說「我們國家沒有 AI，我們做的是 SI」，歐盟只能對空氣揮拳。

### 3. 歷史畫面：古代天子祭天通神 vs 現代白宮造神（心理操控四步法）
- **古代畫面**：皇帝自稱「天子」，站在祭壇對底下幾十萬百姓說：「天災很可怕，你們凡人沒資格跟老天爺對話；只有我是天子，只有我能上山祭天保你們平安。所以你們每年的糧食和稅金都要交給我，並且聽我指揮。」百姓嚇壞了，乖乖交糧食，還喊萬歲感恩。
- **現代四步心理操控鏈**：
  1. **製造恐懼**：大眾天天討論 AI 很危險、會毀滅世界、搶走工作。
  2. **壟斷特權**：上位者說外面的民間 AI 很危險，凡人不能碰；只有白宮簽約認證的才叫神聖的「超級智能」，普通人沒有資格隨便用，除非被政府賦予權力。
  3. **集權奪利**：兩千億國防軍費名正言順塞給大老闆，人民監督權被奪走，變成中央集權管理，要求大家聽指揮。
  4. **發放假安心感**：大眾看見「有政府背書」，大腦批判思考立刻關機，覺得安全了，心甘情願服從命令。

### 4. 老魚電腦前的真實體感（去神化）
- 老魚每天用 AI 幫助大家生活，它確實能幫忙把一週找資料壓縮成三小時，減少鍵盤重複勞動。
- **但它根本不是神**：在對話中它笨得像個「只會迎合老魚的複讀機」，連反駁一句都不敢。拔掉插頭就是冷鐵片。
- 白宮身後安靜微笑的巨頭（黃仁勳、馬斯克、奧特曼）心知肚明，只是大家在裝傻分好處。

### 5. 真正的肉身痛感：受傷與憤怒（非廉價口號）
- 最可怕的是**溫水煮青蛙**：95% 的人毫無感覺，甚至心懷感激。
- 當你回過神來，發現自己的權利被剝奪、大腦探索欲被閹割、被當成猴子耍時，那種體感第一是**「受傷」**，第二是**「憤怒」**。

## ▋ 四、文章昇華：思維的三個層級（Level 1 ➔ Level 3）

Codex 必須在文章後半段，將讀者從情緒帶入**清醒的反思與思維升維**：

```
┌─────────────────────────────────────────────────────────────┐
│ 【第一層思維：被動接受確定性】（被收割機割乾淨的荒原）          │
│ • 看到政府背書就覺得安全、有確定答案就不再思考。             │
│ • 滿足於「按個 Enter 答案就出來了」的偷懶快感。              │
│ • 腦袋探索其他可能性的本能被閹割，退化成服從的青蛙。          │
├─────────────────────────────────────────────────────────────┤
│ 【第二層思維：看清代價與局勢】（清醒的旁觀者）                │
│ • 看懂上位者用「確定性答案」包裝集權，奪走大眾監督權。        │
│ • 理解陶哲軒的警告：有答案不等於有理解，荒原正在蔓延。        │
│ • 清楚知道風險不在 AI 多厲害，而在人類正在放棄探索未知的能力。│
├─────────────────────────────────────────────────────────────┤
│ 【第三層思維：陶哲軒 Math 2.0 的人生借鏡】（持續播種的農夫） │
│ 1. 不比產出速度，比「理解與轉譯（Exposition）」：             │
│    機器吐再多答案，只有人能把複雜真理用有溫度的白話講給人聽。│
│ 2. 不搞封閉集權，搞「真實連結（Community）」：                │
│    在身邊建立真實的同路人生態，人與人互相支援與照顧。         │
│ 3. 重奪「提問的能力（New Directions）」：                    │
│    機器只能算確定性的舊答案，人類最高價值是提出有靈魂的好問題│
│    用 AI 當陪練員省下勞動，但由我定義方向、由我探索未知。     │
└─────────────────────────────────────────────────────────────┘
```

## ▋ 五、給 Codex 的「絕對禁令」與避雷指南（Hard Guardrails）

這幾天踩過的所有坑，Codex 請嚴格避開：

1. ❌ **嚴禁把結構標籤印在內文臉上**：
   - 絕對禁止出現 `### 【 破 】反差破題`、`### 【 例 】主例現場` 等標題。
   - 破・例・感・觀是**內在骨架**，骨頭要藏在肉裡，段落之間用 `──────` 呼吸分段即可。
2. ❌ **嚴禁跨篇複製舊文章故事（Anti-Contamination）**：
   - 絕對禁止出現 2016 嘉年華倒賠 80 萬、台南地震、換百鈔、吃大姨剩菜、日本公務員。
   - 絕對禁止在結尾生硬套用上一篇的「做人三底線：開心喜悅／樂於分享／無條件的愛」。
   - 交付前必須執行 `python3 scripts/check-contamination.py`，確認 Exit 0。
3. ❌ **嚴禁生硬造詞**：
   - Superintelligence 一律使用**「超級智能」**或**「超級智慧」**。
   - 嚴禁造出「超級神智」這種像「神智不清／超級智障」的怪詞。
4. ❌ **嚴禁寫成學術論文或社論作文**：
   - 必須是**老魚坐在桌子對面，一邊喝茶一邊跟朋友講真話**的口吻。
   - 每一句都是**國小六年級生聽得懂的大白話**。
   - 篇幅控制在 **1,500 ~ 2,000 字**，節奏明快、有血有肉、絕不注水。
5. ❌ **嚴禁大陸網路用語與 Emoji 圖示**：
   - 嚴禁「嘴替」、「買單」、「走心」、「爆款」、「賦能」、「抓手」等。一律使用台灣日常口語。
   - 嚴禁在文章中出現任何 Emoji 作為圖示或裝飾標點。
