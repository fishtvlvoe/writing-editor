# 單一通用寫作助手 Agent，能力由 Skills 組成

日期：2026-10-10
狀態：已決定

## 情境
既有 `writing-assistant` Agent 把老魚的稱呼、口吻與寫作模組綁成預設。討論初期曾把通用責任編輯設定帶進新系統，造成像是要提供兩個角色的誤解。

## 決定
只建立一個面向使用者的通用寫作助手 Agent。訪談、查證、文章撰寫和個人風格分析是它使用的 Skills／模組，不是另外的 Agent。每位作者的偏好另存為私人、可選的個人設定；老魚的偏好不作為通用預設。

## 後果
作者只需選一個寫作助手；內部能力可模組化維護。個人設定保存位置須確保不混入共用 Agent/Skill 套件或共享版控。其他現有 Agent 設定不屬於本決策的修改範圍。
