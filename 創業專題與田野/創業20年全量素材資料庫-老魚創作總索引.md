## 第一部：上過的課程與學習素材庫（輸入層）

老魚曾總結：「我曾買過 37 個線上課程，但真正看完的只有 3 個。後來我花了 3 年明白，資訊過載不是學太慢，是學太多；學習不是收藏，輸出才是真正的學習。」

### 1. 早期啟蒙與破產自學期（2001–2011）
- **卡內基訓練 (Carnegie Training)**：
  - **上課內容**：人際關係九大原則、公眾演說五步結構、如何克服憂慮與恐懼、真誠讚賞與人際破冰。
  - **具體轉變**：褪去早期在軍旅環境中的僵硬指令式思維，建立在陌生人面前表達的信心基礎。
- **經營教育學院**：
  - **上課內容**：企業三大報表判讀、團隊組織分工、實體門市運營、股權結構與商業授權體系。
  - **具體轉變**：在 2006 創業初期奠定商業營運框架，但隨後因缺乏現金流意識與過度擴張遭遇門市破產。
- **台南誠品書店「免費蹭書自學」**（2007–2011）：
  - **自學內容**：
    - 行為經濟學（康納曼《快思慢想》、思考的盲點與決策偏誤）。
    - 演化生物學與腦科學（多巴胺獎勵機制、大腦鏡像神經元、人類演化歷史）。
    - 歐美直接反應行銷（Dan Kennedy 磁性行銷、Jay Abraham 槓桿行銷與策略聯盟）。
  - **核心體會**：窮到名下無資產時，大腦是唯一無法被查封的資產。每天在書店站著讀 4~6 小時，將書中框架抄錄在筆記本上反覆推演。
- **哈夏藝術文化「舞台劇表演課」**（2012-10-11）：
  - **上課內容**：
    - 肢體解構與情緒釋放、角色面具 (Persona) 與真實自我的切換。
    - 聲音共鳴訓練、眼神焦點控制、無實物表演與情境沉浸。
  - **實務轉變**：學會「如何在鏡頭前脫去羞怯與自我防衛」，將舞台劇的情緒張力轉化為日後拍攝 YouTube 影片與公眾演說時的感染力。
- **核心價值課程 (Core Values / Core Value Training)**（2007–2023，長達 16 年）：
  - **創辦人與導師**：Linda Chandler（美國 Chandler Leadership & Training / Learning 2000 West）。
  - **上課內容與核心模組**：
    - **內在覺察 (Awareness)**：觀察自己的情緒起伏，不批判、不認同，回到觀察者視角。
    - **責任承擔 (Accountability vs Victimhood)**：從「受害者心態（都是環境、別人害我）」轉變為「100% 責任承擔者（這是我吸引或允許發生的）」。
    - **能量與頻率 (Energy, Frequency & Vibration)**：情緒量表對齊、清理潛意識創傷與金錢匱乏感。
    - **金錢畢業班 (Money Mastery)**：深層重構金錢信念，解開「賺錢是罪惡 / 有錢人不可信 / 負債是羞恥」的心理結。
    - **海外進階班 (CV5, CV6, CV9, CV10, BE)**：柬埔寨、馬來西亞怡保與檳城閉門深度修煉，透過極限對焦看見深層恐懼。
  - **深層轉變**：思想從軍旅「階級論、權威壓制、利益導向」徹底轉向內在真實與利他。
- **海外大師直接反應行銷體系自學**（2010–2015）：
  - **Russell Brunson (ClickFunnels)**：DotCom Secrets 漏斗架構、肥皂劇郵件序列 (Soap Opera Sequence)、日常日常信 (Daily Seinfeld Emails)、高價成交腳本。
  - **Jeff Walker (Product Launch Formula)**：四部發售影片架構、精神誘因 (Mental Triggers)、預熱與開車門成交策略。
  - **Frank Kern**：行為動態行銷 (Behavioral Dynamic Marketing)、核心定位與諮詢顧問成交法。

### 2. 網路行銷與講師認證期（2011–2014）

  - **實戰成果**：取得講師認證，正式開啟政府機構（南區職訓局、高雄新聞局）授課之路。

  - **上課內容**：Facebook 早期粉絲頁演算法拆解、病毒行銷文案、互動率優化、社群危機處理。

### 3. 新竹時期：金融、教練與身心靈認證（2018–2020）
- **天賦原動力 (Wealth Dynamics) / 天賦諮詢師認證**（師從 Roger Hamilton 體系）：
  - **上課內容**：
    - 四大能量：發電機 (Dynamo-創意)、火焰 (Blaze-人際)、節奏 (Tempo-服務感應)、鋼鐵 (Steel-細節系統)。
    - 八大特質角色：創作者、明星、推廣者、媒合者、交易者、積蓄者、地主、機械師。
    - 財富光譜 (Wealth Spectrum)：基礎層、順流層、平流層、逆流層的財務晉級路徑。
  - **應用場景**：日後為數百位企業主與個人進行「黃金三角團隊盤點」與一對一高階顧問諮詢。
- **財富流沙盤教練 (Wealth Flow Coach)**（師從九哥）：
  - **上課內容**：沙盤推演機制、精力/時間/人脈/金錢四維資產配置、九大逆流覺察與破局技巧。
- **執行動力 346 期體驗培訓**：
  - **上課內容**：高壓密閉團隊破冰、承諾與突破極限、直面人際衝突與真實反饋。
- **敏捷式團隊工作術 (Scrum & Kanban)**：
  - **上課內容**：使用者故事拆解、每日站會 (Daily Standup)、Sprint 迭代週期、回顧會議 (Retrospective)。
- **心成能量學**：
  - **上課內容**：身體能量場、脈輪感知、關係修復。
  - **反思退出**：因察覺私下互動存在強烈的情緒依附與操控 (PUA) 傾向，果斷止步，拒絕進入高階圈子。
- **賴佩霞「中華好好說話學會」溝通研討會**：
  - **上課內容**：非暴力溝通 (NVC) 四要素（觀察、感受、需要、請求）、放下評判、深層傾聽與家庭代際和解。

### 4. 谷底轉念與佛學哲學期（2021–2026）
- **《當和尚遇到鑽石》種子法則 (DCI 體系)**（師從格西麥可·羅區體系，由旅澳教練 Jenny 引導）：
  - **上課與操練內容**：
    - **筆的原理 (The Pen Story)**：空性 (Emptiness) 與潛能，明白外在一切皆由自己過去種下的意識種子所投射。
    - **四步驟 (4 Steps)**：
      1. 用一句話說出你想要的。
      2. 找到一個有相同需求的人，計劃如何幫助他。
      3. 每週付出行動去幫助他。
      4. **咖啡冥想 (Coffee Meditation)**：睡前帶著喜悅的心情回想自己幫助他人的畫面（給種子澆水）。
    - **四力量 (4 Powers)**：清理過去種下的負面壞種子（明智悔過、立誓不再犯、採取補償動作）。
    - **C14 清理隱形負債法**：每月誠實、準時、帶著感恩償還每一筆債務與股東款，化解恐懼與匱乏感。
- **斯多葛哲學 (Stoicism) 與先秦諸子現代演繹**：
  - **核心體系**：
    - 區分「我能控制的（行動、起心動念、誠信）」與「我不能控制的（外界評價、市場波動、他人回報）」。
    - 結合現代認知科學與資訊理論，淬鍊為「電馭工作流」與「認知熵減」架構。
