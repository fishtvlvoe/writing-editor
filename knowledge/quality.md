# 文章品質檢查

## 內部校稿評分

每篇完成稿以五個面向各自檢查，1–10 分只作為找出需要修改處的工作尺，不是客觀成績，也不會取代作者的定稿決定。不適用的面向記為 N/A；沒有已確認個人風格時，只檢查有沒有遵守本篇明確要求，不推測作者口吻。

| 面向 | 檢查內容 | 分數 |
|---|---|---|
| 事實可靠 | 外部事實有來源，限制與不確定處標示清楚 | /10 |
| 觀點完整 | 核心看法來自作者確認，沒有擅自替作者下結論 | /10 |
| 邏輯連貫 | 段落順序合理，因果和轉折接得起來 | /10 |
| 讀者適配 | 目標讀者、平台與長度符合本篇需求 | /10 |
| 作者聲音 | 使用已確認的個人設定；無設定時不假裝熟悉作者 | /10 |

任何適用面向低於 8 分時，先修正該面向並再次檢查。分數預設不展示給作者；只回報具體可改之處。無論分數如何，是否定稿仍由作者決定。

## 定稿前檢查

- [ ] 目標讀者、文章目的與作者確認過的核心看法一致。
- [ ] 每個重要外部事實都有可靠來源，或明確標為未確認。
- [ ] 作者經驗、觀點與外部事實分清楚；沒有杜撰經歷、情緒、對話或動機。
- [ ] 段落前後連得起來，每一段都在服務文章主線。
- [ ] 選用作者已確認的個人風格設定；沒有設定時不假裝知道作者口吻。
- [ ] 作者選用的結構、平台與長度有落實；未選用的模組沒有被硬套。
- [ ] 沒有把歷史文章的人物、故事或情節移植進本篇，除非作者這次明確提供或確認。
- [ ] 篇幅、段落節奏與用語符合作者指定平台和讀者理解程度。
- [ ] 文章已明確標示為草稿或定稿；未經作者確認不標定稿。
- [ ] 未經明確要求，不發布、寄送或提交到外部平台。

檢查不通過時，指出具體問題與修改方案，讓作者決定；不要用漂亮句子掩蓋事實或立場缺口。
