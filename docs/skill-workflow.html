爆文寫作 Skill 運作流程圖解

就像「去高級餐廳客製大菜」：先聊口味 ➔ 寫食譜規格 ➔ 進廚房開火，每步都有紅綠燈

階段一 Discuss（討論對焦）— 決定這道菜要什麼味道

這個階段雙方只聊天對焦，完全不動筆寫長文。

老魚：
「我想寫川普把 AI 改成 SI 的新聞，字數越多越好。」
AI（寫作助理）：
1. 立刻幫你上網查第一手事實（新聞、法案編號、馬斯克改名、各界反應）。
2. 拿出 8 個切角鏡頭（錢、權力、情緒等），一題一題問你。
3. 找到你最共鳴的核心：「有權力的人隨便劃分世界，一般人承擔代價（權力三角）」。
【紅綠燈 Gate 1】 討論到此收斂，AI 必須停下來問你：「方向確定了，我們要不要立案寫規格？」 你點頭才准過
▼
階段二 Propose（立案寫食譜）— 產出標準 SR 規格清單

把剛才聊天的內容，像寫程式一樣規格化成 3 份檔案，防止腦袋要硬記：

writing-editor/changes/writing-trump-si/
├── proposal.md   ➔ 【核心動機】打穿「上位者搶奪解釋權」的虛偽
├── design.md   ➔ 【材料清單】事實網址庫 + 權力三角 + 老魚語態引擎
└── tasks.md   ➔ 【烹飪步驟】Task 1、2、3（每步寫明目的與驗收標準 DoD）
【紅綠燈 Gate 2】 規格已立死，AI 必須停下來問你：「清單都排好了，我們正式開火動筆嗎？」 你點頭才開火
▼
階段三 Apply（進廚房炒菜）— 照清單逐條實作與交付

AI 像跑自動化測試一樣，一步一步打勾完成：

[✓] 步驟 1：按「破・例・感・觀」組裝冷暖雙鏡頭大綱。
[✓] 步驟 2：按「老魚親修語態」極致擴寫（名詞＋動詞、大同電鍋白蒸氣、精確數字）。
[✓] 步驟 3：跑標題工程，產出 5 組高張力標題任你挑。
[✓] 步驟 4：雙路徑存檔交付到 ~/Downloads/ 與專案資料夾。
