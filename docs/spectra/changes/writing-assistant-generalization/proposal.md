## Why

現有的「寫作助手」Agent 把老魚的口吻、訪談習慣與寫作模組寫成固定規則，其他作者無法用自己的風格設定。這次要把它整理成**一個通用寫作助手 Agent**：共通流程由可拆分的 Skill 能力支援，每位作者可自行建立、修改並選擇保存自己的偏好。

## What Changes

- 將既有寫作助手 Agent 改成通用入口；不新增第二個面向使用者的「責任編輯」角色。
- 提供從訪談、查證、大綱、初稿、修稿到作者確認定稿的完整文章寫作流程。
- 加入可選的作者風格建立流程：作者可提供代表文章，或選擇分析指定帳號在指定期間內、本人撰寫的原創文章。
- 風格分析先產出摘要與示範改寫，交由作者確認；作者同意後才可保存。個人設定可查看、修改、刪除，並可另設平台風格。
- 訪談採開放式一題一問；先協助作者自己想清楚，不以選項替作者決定。只有作者明確要求發想時，才提供清楚標示的建議。
- 第一版支援社群貼文、部落格與網路文章。帳號內容無法讀取時，改請作者貼上或提供匯出內容；不索取帳號密碼。

## Non-Goals

- 不把老魚的個人偏好設成所有使用者的預設。
- 不擴充成電子郵件、企劃書、報告等所有文字類型。
- 不自動保存作者偏好、把單篇素材寫入長期設定，或未經作者確認就發布文章。
- 不新增第二個面向使用者的 Agent，也不修改其他 Agent 設定。

## Capabilities

### New Capabilities

- `article-writing-workflow`: 通用文章 Agent 的逐題訪談、查證、大綱確認、起草修稿與定稿交付。
- `author-style-profile`: 作者提供或授權的文章風格分析、摘要與示範確認、個人及平台偏好設定與保存控制。

### Modified Capabilities

無；目前沒有既有的 Spectra 能力規格。

## Impact

- 修改 `agents/writing-assistant.yaml`，移除綁定單一作者的預設，改為通用寫作助手。
- 新增並模組化寫作助手使用的 Skill 流程與作者風格設定能力。
- 以不同作者、平台差異、無樣本、帳號內容讀取失敗、修稿與未授權發布等情境驗收。
- `agents/openai.yaml` 與既有其他 Agent 不在本案範圍。
