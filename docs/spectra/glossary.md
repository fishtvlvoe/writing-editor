# 寫作助手領域詞彙

- **寫作助手 Agent**：使用者直接對話的單一入口；負責協調訪談、查證、起草、修稿與交付。
- **Skill／能力模組**：Agent 內部使用的流程指引或專項能力，不是另一個使用者角色。
- **作者風格設定**：作者選擇建立並核准的個人寫作偏好；與共用 Agent/Skill 分離。
- **風格建立流程**：作者可跳過的流程；以樣本或授權範圍內可讀取的原創文字提出風格摘要和示範改寫。
- **帳號分析範圍**：作者指定的平台或來源及時間範圍；只分析可讀取且可歸屬作者的原創內容。
- **平台風格差異設定**：在共通作者風格上，選擇性加入特定平台的格式或口吻差異。
