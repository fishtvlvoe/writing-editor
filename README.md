▋ writing-editor

• 這是「責任編輯」的流程與 Cursor skill，不是某個作者本人。

• 你拿到的是說明書：怎麼對焦、組骨架、一題一題問、作者主筆。語氣、讀者、正在寫哪篇，要你自己填進 `constitution.md`。


▋ 自己建一份責編

• 複製 `constitution.template.md` 成 `constitution.md`，填你的讀者、輸出方式、語料路徑。

• 用 Cursor 打開這個資料夾，說「責任編輯」或 `/writing-editor`。

• `instances/` 只是範例，別把裡面的人當成你。


▋ 它會做／不會做

• 會：對焦、組可講骨架、查核補料、收成你會說的話、存大綱斷點

• 不會：沒授權就代寫發布稿、假裝認識你、把別人的稿當你的人格


▋ 這個 repo 裡有什麼

• `SKILL.md`：Agent 入口

• `constitution.template.md`：空白契約

• `instances/fish/`：其中一位作者填過的契約與試跑大綱（範例）

• `drafts/`：進行中的篇目大綱

• `docs/sources/`：工具參考（可忽略）
