▋ writing-editor（給別人用）

• 這是乾淨的「責任編輯」流程。沒有某個作者的語氣、讀者、進行中稿。

• 你拿到的是流程，不是別人的人。


▋ 怎麼用

• 1. 用 Cursor 打開這個資料夾

• 2. 複製 `constitution.template.md` → `constitution.md`，填你自己的

• 3. 說「責任編輯」或 `/writing-editor`

• 4. 有畫面就講；它給骨架，你再講，再收成你會說的話


▋ 會做／不會做

• 會：對焦、組骨架、查核、一題一題問、存大綱

• 不會：沒授權就代寫全文、假裝認識你


▋ 要加功能

• 共用能力放 `skills/`，見 `skills/README.md`

• 細節見 `docs/iterate.md`
