# 寫作助手

本 repo 提供**一個面向使用者的通用寫作助手 Agent**。Agent 使用根目錄 `SKILL.md` 的共同流程，並按作者選擇載入 `skills/` 內的能力模組；模組不是額外的對話角色。

## 寫作流程

訪談 → 查證 → 大綱確認 → 完整初稿 → 修稿 → 作者確認定稿

第一版支援社群貼文、部落格與網路文章。訪談一次只問一個開放問題；文章觀點、定稿與發布由作者決定。

## 個人風格設定

首次使用可選擇提供文章樣本、授權分析指定帳號與期間，或跳過直接開始寫作。風格摘要與示範改寫須經作者確認；只有作者明確同意後，才保存到使用者私有設定目錄 `~/.config/writing-assistant/author-profile.md`。

個人設定、原始樣本、草稿與已發表文章不放進共用 Agent/Skill 套件或 repo。帳號來源讀不到時，請作者貼上或提供匯出內容；不索取帳密。
