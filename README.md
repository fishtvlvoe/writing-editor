▋ writing-editor（通用中文文章責編 Skill）

• 給任何作者使用的中文文章責編流程。
• 內建通用文章架構 `po-li-gan-guan`：破、例、感、觀。
• 先問作者想寫什麼，再一題一題訪談；作者主筆，責編不代寫全文。


▋ 怎麼用

• 1. Cursor 打開這個資料夾

• 2. 需要保存作者偏好時，複製 `constitution.template.md` → `constitution.md`，填自己的

• 3. 說「責任編輯」或 `/writing-editor`


▋ 作者契約與發布邊界

• `constitution.md` 是本機作者契約，不是通用 Skill 的必要檔案。
• 發布通用 Skill 時，只發布流程、架構與模板，不發布任何作者私人契約、草稿或已發表文章。

• 作者自己的語氣、素材與平台規則，放在自己的契約或私有模組。

• 個人資料永不進這個 repo
