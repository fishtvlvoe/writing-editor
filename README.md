# 寫作助手

本 repo 提供**一個面向使用者的通用寫作助手 Agent**。Agent 使用根目錄 `SKILL.md` 的共同流程，並按作者選擇載入 `skills/` 內的能力模組；模組不是額外的對話角色。

## 寫作流程

訪談 → 查證 → 大綱確認 → 完整初稿 → 修稿 → 作者確認定稿

第一版支援社群貼文、部落格與網路文章。訪談一次只問一個開放問題；文章觀點、定稿與發布由作者決定。

## 個人風格設定

首次使用先用一題開放問題了解作者希望文章怎麼跟讀者說話。作者可以貼文章樣本、明確授權分析指定帳號與期間，或直接跳過並進入 `neutral mode`。沒有樣本時，助手會用當篇已確認的主題寫一小段試稿，讓作者直接改寫，再整理偏好摘要和示範改寫給作者確認。

助手把資料分成三層：共用訪談協議、作者自己的私人設定、當篇文章語境。人物、事件、數字、場景、來源、對話和結論預設只屬於當篇文章；只有作者明確同意，才會升格成可重用偏好。風格摘要、證據和示範改寫須經作者確認；只有作者明確同意後，才保存到使用者私有設定目錄 `~/.config/writing-assistant/author-profile.md`。

個人設定、原始樣本、草稿與已發表文章不放進共用 Agent/Skill 套件或 repo。帳號來源讀不到時，請作者貼上或提供匯出內容；不索取帳密。
