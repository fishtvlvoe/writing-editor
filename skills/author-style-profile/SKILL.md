# 作者風格設定

本模組是選配能力。作者可以直接開始寫作，不提供樣本、不分析帳號，也不必建立個人設定。沒有已確認的設定時，不要宣稱知道作者的個人風格。

## GATE：先確認資料範圍

- 分析帳號前，先重述作者指定的平台／帳號與時間範圍，並取得明確同意；一輪只問一個待確認項目。
- 沒有既有設定時，先問一個開放問題了解作者希望文章怎麼跟讀者說話，不用固定風格選單替作者回答。
- 作者沒有樣本或不授權帳號分析時，完成文章目標訪談後，使用當篇已確認素材產生短段落供作者直接修改；修改前不推斷長期偏好。
- 保存風格卡前，先讓作者檢視摘要和示範改寫，再另外取得明確保存同意。
- 修改或刪除既有設定時，先確認這次要改動或移除的內容；未確認前不寫入、不刪除。

## 建立風格卡

先問作者要分析其挑選的樣本，還是分析指定帳號中的原創內容。帳號分析開始前，請作者明確指定平台／帳號與時間範圍，並明確同意分析該範圍。只使用可存取且可歸屬作者本人的原創文字；排除轉貼、引用他人內容及無法確認作者的內容，並說明涵蓋範圍與限制。不得索取密碼、登入憑證或要求作者交出帳號存取權。

讀不到帳號或貼文時，清楚說明哪些內容未讀取，請作者貼上選定內容或提供匯出檔。不要假稱已分析連結。原始樣本只供本次分析，不寫入個人設定、Skill、Agent 或其他長期記錄；分析完成後不保留樣本副本。

根據實際樣本整理可觀察的用字、句長、節奏、敘事方式、情緒表達與明確偏好。區分觀察與推測，不用少量樣本推斷作者未表達的立場或人格。呈現一張簡短風格卡及一段依該風格改寫的示範，請作者檢視。作者提出修正時，更新兩者並再次請作者確認。

### 沒有樣本時的試寫校準

完成本篇文章的讀者、用途、主題和必要素材訪談後，從已確認的當篇內容寫一小段試稿。試稿只用來讓作者修改，不是作者已確認的文風證據。作者可以直接重寫、圈出不自然的地方、補充「我會怎麼說」，或說明這段完全不像自己。

整理候選偏好時，分開標示：

- **作者明說**：作者直接說出的偏好或禁用方式。
- **修改證據**：作者在試稿中實際改過的句子和可觀察差異。
- **助手推測**：助手根據少量修改提出的暫定解讀，不能直接保存。

如果作者否認助手推測，該規則刪除或退回未確認狀態。若只有一個短段落能支持某項偏好，標示證據有限，不把它寫成作者固定人格或所有主題都適用的規則。

### 保存前審閱卡

保存前必須展示一張簡短審閱卡：

1. 偏好規則：用作者看得懂的白話寫。
2. 來源證據：作者明說、修改示範，或已確認樣本。
3. 適用範圍：共通口吻、特定平台，或只限本篇。
4. 不確定處：樣本太少、解讀仍待確認的地方。
5. 示範改寫：讓作者能直接判斷「像不像我」。

作者明確同意前，審閱卡只是當次候選設定，不寫入私人檔案。

只有作者明確同意保存這張已確認的風格卡後，才將其存到個人設定路徑：優先使用作者明確指定且位於 repo 外的 `WRITING_ASSISTANT_PROFILE_PATH`，否則使用 `~/.config/writing-assistant/author-profile.md`。寫入前確認路徑位於共用 repo 之外；經同意後才建立缺少的私人設定目錄。若路徑位於共用 repo 內或執行環境無法寫入，明確說明未保存；可提供風格卡文字供作者自行保存。作者未同意保存、跳過或拒絕時，設定僅供當次對話使用，不得持久化。

## 使用與管理設定

- 作者要求查看時，讀取並展示其個人設定；檔案不存在或無法讀取時，據實說明。
- 作者要求修改時，先呈現修改後內容供作者確認；只有作者明確要求套用該修改時，才更新個人檔案。
- 作者要求刪除時，刪除該作者的個人設定並確認結果；若無法執行刪除，說明限制，不宣稱已刪除。
- 個人設定只屬於目前作者，不得引用其他作者的設定，也不得把設定併入共用 Agent 或 Skill。
- 單篇文章的事實、立場、素材與草稿不自動加入長期設定。新增長期偏好須由作者明確提出並確認。
- 文章人物、事件、數字、場景、來源、對話和結論預設屬於當篇語境；只有作者明確要求長期保留，才可升格為私人偏好。

設定由一種共通口吻和零個以上的平台差異組成。寫作時先套用共通口吻，再套用作者已確認的平台差異；沒有該平台設定時，只依作者本次要求與平台格式撰寫，不可捏造既有偏好。欄位格式見 [個人設定範本](references/profile-template.md)。

## 品質檢查

- [ ] 每條風格觀察都能連回作者提供且可讀取的文字，或作者明確確認的偏好。
- [ ] 樣本數量與涵蓋期間如有限，已標示分析限制。
- [ ] 沒有從文風推斷人格、動機或未說出的立場。
- [ ] 示範改寫能讓作者確認或指出差異。
- [ ] 沒有把原始樣本、草稿或個人設定寫入共用 Skill、Agent 或 repo。
- [ ] 沒有把當篇人物、事件、數字、場景、來源、對話或結論誤存成長期偏好。

## 完成條件

- [ ] 作者選擇建立或管理個人風格設定；略過時不阻擋寫作。
- [ ] 無樣本作者能用當篇試寫修改完成候選偏好校準，或明確選擇 neutral mode。
- [ ] 帳號分析使用明確同意的來源與期間，且只採用可歸屬作者的原創內容。
- [ ] 作者已檢視風格卡和示範改寫。
- [ ] 審閱卡清楚區分作者明說、修改證據和助手推測。
- [ ] 設定只在作者明確同意後保存；未同意時僅供當次使用。
- [ ] 作者可查看、修改或刪除個人設定。
