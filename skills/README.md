▋ 這層是什麼

• 根目錄 `SKILL.md` 是寫作助手共用主流程：訪談、查證、大綱、起草、修稿與定稿確認。

• `skills/` 放可選能力模組。模組只有在作者偏好已選用或作者明確提出時才載入；不要把某位作者的模組當成所有人的預設。

• `po-li-gan-guan` 是一種文章組織架構，不是作者文體，也不是每篇文章的固定模板。作者選用時才讀取。

• `author-style-profile` 是作者個人風格設定工具。它可選、要先取得作者同意；個人設定保存在共用 repo 以外。

▋ 怎麼加一個模組

• 1. 建 `skills/<英文短名>/SKILL.md`

• 2. 在 `skills/manifest.md` 登記模組用途與載入條件

• 3. 改 `VERSION`（小功能 +0.0.1，新增能力或行為變更 +0.1.0，不相容 +1.0.0）

• 4. 在 `CHANGELOG.md` 寫新增能力與作者需知道的設定變更

• 5. 用代表情境試跑，確認主流程仍可略過此模組

• 6. commit／push

▋ 模組 SKILL.md 最低限度

• YAML：`name`、`description`（清楚說明何時載入）

• 正文：模組可做／不可做、輸入、輸出與資料保存邊界

• 不要複製或改寫主循環；主流程只在符合載入條件時呼叫模組
